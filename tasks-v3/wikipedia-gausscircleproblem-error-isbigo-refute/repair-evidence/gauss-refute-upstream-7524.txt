In
#7286
and
#7431
we have added tags to link particular declarations to the
optimization constants
webpage. In reviewing the repo, Claude found some other references to constants from the site, but in ways that I haven't tagged yet, because the definitions aren't as straightforward to refactor out (i.e. the constant of interest doesn't necessarily just appear as a term).
Still, I think it would probably be nice to refactor most of these to extract a taggable definition for the constant of interest, so that we can have the link to the site and also isolate the constant to make it easier to state more conjectures about later. Here's a list of all the files in formal-conjectures Claude found that might be targets for this kind of refactor:
1b
: Erdős minimum overlap constant (
ErdosProblems/36.lean#L260
)
5a
: Sidon set size constant (
ErdosProblems/30.lean#L79
)
6a
: Union-closed sets conjecture constant (
Wikipedia/UnionClosed.lean#L59
)
feat(OptimizationConstants): add 6a
#7528
9a
: Shannon capacity of the 7-cycle (
GreensOpenProblems/38.lean#L73
)
17a
: Exponential growth constant of diagonal Ramsey numbers (
ErdosProblems/77.lean#L54
)
There is an interesting side case here: It has not actually been proved that the limit stated in this constant's page exists. Thus, formally speaking, this is not really a well-defined constant. The page says "For the purposes of this page, upper (resp. lower) bounds on C_17 should be interpreted as bounding the limit superior (resp. limit inferior)." It's not obvious what the best way to resolve this is for the purposes of formal-conjectures tagging, some options could be to define the lim inf and/or lim sup and tag one (which runs the risk of interpreting statements from the constants site the wrong way) or both (which breaks the conceptual invariant that all constants should have only one tag).
24a
: Komlós discrepancy constant (

)
27a

)

)

Reorganizing some of this content into the

Porting additional content from the site to formal-conjectures
Other constants

research solved
